# Nom et logo Jabba / Jabba name and logo

## Français

Le nom **« Jabba »**, comme nom de ce logiciel, et son logo (les icônes de `app/static/icone-*.png`) ne sont **pas couverts** par la licence du code (fichier `LICENSE`).

Ce qui est permis sans demander :

- utiliser Jabba tel quel, avec son nom et son logo, y compris pour un usage professionnel ;
- parler de Jabba, le citer ou indiquer qu'un outil est « compatible avec Jabba ».

Ce qui demande une autorisation écrite de Macr0b :

- utiliser le nom « Jabba » ou le logo pour une version modifiée, un autre logiciel, un service ou un produit ;
- utiliser un nom ou un logo assez proche pour créer une confusion avec ce logiciel.

Une version modifiée doit donc porter un autre nom et un autre logo, et ne pas laisser croire qu'elle vient de l'auteur de Jabba.

## English

The name **"Jabba"**, as the name of this software, and its logo (the icons in `app/static/icone-*.png`) are **not covered** by the code license (`LICENSE` file).

Allowed without asking:

- using Jabba as is, with its name and logo, including for professional work;
- talking about Jabba, quoting it, or stating that a tool is "compatible with Jabba".

Requires written permission from Macr0b:

- using the name "Jabba" or the logo for a modified version, another software, a service or a product;
- using a name or logo close enough to be confused with this software.

A modified version must therefore use another name and another logo, and must not suggest that it comes from the author of Jabba.
